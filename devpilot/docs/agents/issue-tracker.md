# 问题追踪器：本地 Markdown

本仓库的 issue 和需求文档（PRD）存储在 `.scratch/` 目录下的 Markdown 文件中。

## 约定

- 每个功能一个目录：`.scratch/<功能名称>/`
- PRD 文件位于：`.scratch/<功能名称>/PRD.md`
- 实现 issue 文件位于：`.scratch/<功能名称>/issues/<编号>-<描述>.md`，编号从 `01` 开始
- 追踪状态记录在每个 issue 文件顶部的 `Status:` 行中（角色字符串定义见 `triage-labels.md`）
- 评论和对话记录追加到文件末尾的 `## 评论` 标题下

## 当技能说"发布到问题追踪器"

在 `.scratch/<功能名称>/` 下创建新文件（如果目录不存在则先创建）。

## 当技能说"获取相关工单"

读取引用路径下的文件。用户通常会直接传递路径或 issue 编号。
